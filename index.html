Taller Práctico — Formularios en HTML

🧠 Parte 1 — Preguntas y Respuestas

1. ¿Qué es un formulario en HTML?
Es un conjunto de campos que permite al usuario ingresar datos en una página web para enviarlos al servidor.

2. ¿Para qué sirve la etiqueta <form>?
Sirve para crear el formulario y definir cómo y a dónde se enviarán los datos.

3. Diferencia entre método GET y POST
GET envía los datos por la URL y es visible. POST envía los datos de manera oculta y es más seguro.

4. ¿Qué es validación de datos en formularios?
Es verificar que los datos ingresados cumplan ciertas reglas antes de enviarse.

5. Mencione 5 tipos de inputs en HTML
text, email, password, number, date.
